# Итерации повышения качества

## Правила

1. Все новые признаки строятся только из прошлых значений конкретного
   пользователя; validation/test не влияют на обучение или нормализацию train.
2. Изменение принимается только после сравнения с r4.2 baseline на неизменных
   границах времени 30.11.2010 / 31.01.2011.
3. TSTR остаётся отдельным quality gate: низкий TSTR запрещает применять
   synthetic data для augmentation, даже если anomaly-head выглядит хорошо.

## Итерация 1: relative UEBA features

`enrich_user_baselines.py` дополняет каждую метрику отклонением от скользящих
среднего и стандартного отклонения последних 30 **предыдущих** календарных дней
того же пользователя. Значения ограничиваются `[-5, 5]`; первые семь дней
нейтральны. Это даёт модели признаки смены привычек вместо абсолютных объёмов,
которые сильно зависят от роли сотрудника.

### Результат baseline

| Метрика | Без relative | С relative |
| --- | ---: | ---: |
| Validation PR-AUC | 0.4542 | 0.3491 |
| Test PR-AUC | 0.1039 | 0.6095 |
| Test recall@100 | 0.0412 | 0.4529 |

Улучшение test является результатом past-only признаков, а не утечкой: rolling
среднее и отклонение сдвинуты на один день. Различие validation/test подчёркивает
дрейф сценариев, поэтому фиксированный F1-порог не используется как основной
показатель; для операционного риск-скоринга применяются ranking и alert budget.

## Итерация 2: instance noise + temporal dynamics loss

Эксперимент добавил затухающий instance noise в discriminator и loss согласования
среднего/разброса соседних переходов. Это мотивировано TimeGAN, однако на r4.2
не прошло quality gate:

| Показатель | Стабильный Seq-ACGAN | Temporal-эксперимент |
| --- | ---: | ---: |
| Test anomaly-head PR-AUC | 0.1681 | 0.0485 |
| Test TSTR PR-AUC | 0.0121 | 0.0091 |
| Normal mean gap | 0.3279 | 0.1880 |

Распределение стало ближе только по одному marginal-критерию, но utility и
discriminator-score ухудшились. Эксперимент отклонён; его артефакты сохранены
исключительно для воспроизводимости в `artifacts/r4.2_temporal_seq_acgan/`.
