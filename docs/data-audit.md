# Аудит данных CERT

## Выбранный выпуск для первого воспроизводимого прогона

- **Источник:** CERT Insider Threat Test Dataset, CMU Software Engineering
  Institute, DOI `10.1184/R1/12841247.v1`.
- **Основной выпуск:** `r3.1` (архив около 4.25 GB), с размеченными сценариями
  `r3.1-1.csv` и `r3.1-2.csv` из `answers.tar.bz2`.
- **Вспомогательный выпуск:** `r1` (архив около 88 MB) — только smoke-test
  нормального поведения. Его нельзя использовать для supervised-обучения:
  официальный answer key начинается с r2.
- **Причина:** r3.1 уже содержит метки аномалий, но существенно компактнее
  поздних выпусков. Загрузчик совместим с `r4.2` без изменения кода.

## Воспроизводимая загрузка

```powershell
python scripts/download_cert.py --release r3.1 --include-answers --extract
```

Скрипт получает перечень файлов из API официальной записи Figshare, скачивает
архивы в `data/raw/cert/archives/`, безопасно распаковывает их и печатает
SHA-256. Исходные данные намеренно исключены из Git.

## Что проверить после загрузки

1. Состав CSV/журналов, их схему, временной диапазон и число пользователей.
2. Состав answer key и соответствие его идентификаторов журналам.
3. Долю аномальных пользовательских временных окон после разметки.
4. Наличие типов событий для признаков: logon, device, file, HTTP и email.

## Результат первичной проверки r1

- Период активности: декабрь 2009 — май 2011; около 1 000 пользователей.
- `http.csv`: 3 451 664 события; `logon.csv`: 849 579; `device.csv`: 65 668.
- Схема событий: `id,date,user,pc,payload`, где payload — URL или действие.
- Есть ежемесячные LDAP-снимки с ролью пользователя.
- В этом выпуске нет строк answer key, поэтому метка `anomaly` недоступна.
