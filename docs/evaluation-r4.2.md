# Оценка стабильного Seq-ACGAN на r4.2

| Показатель | Validation | Test |
| --- | ---: | ---: |
| anomaly-head PR-AUC | 0.2277 | 0.1681 |
| anomaly-head ROC-AUC | 0.9000 | 0.9674 |
| anomaly-head recall@100 | 0.2286 | 0.1588 |
| Baseline PR-AUC | 0.4542 | 0.1039 |

На test anomaly-head улучшает PR-AUC относительно baseline (`0.1681` против
`0.1039`), однако на validation baseline лучше.

Генеративное качество заметно улучшилось: разрыв средних/стандартных
отклонений составляет 0.28–0.33 и 0.20–0.21 в bounded-пространстве, вместо
десятков единиц в первом r3.1-прогоне.

TSTR пока слаб: test PR-AUC `0.0121`, recall@500 `0`. Поэтому синтетические
последовательности **не применяются для augmentation** в этой версии. Модель
годится как исследовательский детектор и генератор для контролируемой
демонстрации, но не как доказанно полезный источник обучающих примеров.
