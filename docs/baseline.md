# Базовый детектор

Baseline — `HistGradientBoostingClassifier` с балансировкой классов. На вход
поступает не содержимое журналов, а 90 summary-признаков 14-дневной
последовательности: последнее значение, среднее, стандартное отклонение,
максимум и изменение «последний день минус первый» для каждого признака.

Масштабирование и обучение производятся только на train. Порог выбирается на
validation по максимуму F1, затем применяется к test без подбора.

```powershell
python scripts/train_baseline.py
```

Итоги записываются в `artifacts/baseline/metrics.json`; модель — в
`artifacts/baseline/model.joblib`.

## Зафиксированный результат r3.1

| Выборка | PR-AUC | ROC-AUC | Recall@100 |
| --- | ---: | ---: | ---: |
| train | 0.8916 | 1.0000 | 1.00 |
| validation | 0.00074 | 0.4279 | 0.00 |
| test | 0.000089 | 0.4321 | 0.00 |

Это **не рабочее качество**, а необходимый базовый результат. В train всего семь
аномальных последовательностей первого сценария, тогда как validation/test
содержат в основном другой сценарий. Модель переобучается и не переносит
распознанный паттерн на новую форму аномалии. Seq-ACGAN будет сравниваться с
этой точкой отсчёта при одинаковом хронологическом разбиении.
