# Текущий лучший детектор r4.2

## Выбор

Текущая модель риска — `artifacts/r4.2_final_raw_baseline/model.joblib`.
Это `HistGradientBoostingClassifier` на summary-признаках 14-дневной
последовательности. После подбора подхода на validation она переобучена на
объединении train+validation (до 31.01.2011) и проверена на последующем test.

## Независимый test

| Метрика | Значение |
| --- | ---: |
| PR-AUC | **0.9049** |
| ROC-AUC | 0.9992 |
| Recall@50 | 0.2941 |
| Precision@50 | 1.00 |
| Recall@100 | **0.5706** |
| Precision@100 | **0.97** |
| Recall@500 | 0.9824 |
| Precision@500 | 0.334 |

Relative-вариант также силён (test PR-AUC 0.8818), но уступает raw-варианту
по PR-AUC; поэтому он остаётся дополнительным диагностическим признаком, а не
основным risk scorer.

## Честная интерпретация

Validation-метрики финальных артефактов не являются независимой оценкой,
поскольку validation использовался при final-refit. Для итогового результата
учитываются только показатели последующего test. В реальном развёртывании
модель должна периодически дообучаться только на уже прошедшем периоде.

## Статус Seq-ACGAN

Seq-ACGAN сохраняется в проекте как двухголовая последовательностная модель и
генератор контролируемых сценариев. Его synthetic data пока не используются
для augmentation: TSTR не прошёл quality gate. Это ограничение не влияет на
доступность высококачественного risk scorer выше.
