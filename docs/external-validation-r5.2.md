# Внешняя валидация: r4.2 → r5.2

Замороженный detector `r4.2_final_raw_baseline` применён без дообучения к
независимому r5.2 test-периоду после 31.01.2011. Это 216 813 последовательностей
и 340 аномальных окон.

| Метрика | Значение |
| --- | ---: |
| PR-AUC | 0.0853 |
| ROC-AUC | 0.7210 |
| Precision@50 | 0.64 |
| Recall@50 | 0.0941 |
| Precision@100 | 0.36 |
| Recall@100 | 0.1059 |

Результат существенно слабее внутривыпускного r4.2 test. Это честно выявляет
dataset/domain shift: новые сценарии и другой генератор журналов нельзя считать
той же самой производственной средой. Внешняя проверка не отменяет качество
r4.2-модели, но запрещает утверждать универсальный перенос без калибровки.

Практический вывод: при развёртывании модель должна сначала собрать историю
организации и быть дообучена/калибрована на её прошедшем периоде; новые выпуски
CERT служат независимым стресс-тестом, а не источником тестовой утечки.
