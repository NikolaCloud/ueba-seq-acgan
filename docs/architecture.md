# Архитектура Seq-ACGAN UEBA

```text
Сырые журналы CERT -> нормализация -> временные окна пользователя -> признаки/токены
                                                                     |
                     +-----------------------------------------------+
                     |                                               |
                 Seq-Generator                                Seq-Discriminator
              z + класс + контекст                         последовательность + контекст
                     |                                               |
              synthetic sequence                    +----------------+----------------+
                                                    |                                 |
                                           source head                       anomaly head
                                        real / synthetic                  normal / anomaly
```

## Контракт модели

- Вход детектора: последовательность оконных событий пользователя и контекст
  (роль, подразделение, время, если доступны и разрешены датасетом).
- Выход: `P(anomaly)`, откалиброванный риск `0..100`, класс и факторы,
  повлиявшие на результат.
- Генератор: `noise + target_class + context -> sequence`; редкий класс
  аномалий можно генерировать целенаправленно для augmentation.
- Дискриминатор имеет две независимые головы, как требуется: `source` для
  отличия настоящих данных от синтетики и `anomaly` для определения нормы/
  аномалии.

## Важные правила эксперимента

1. Разбиение только по времени: будущее не используется для формирования
   признаков прошлого.
2. Ответы (answer key) используются только для меток и оценки, а не как признак.
3. Генератор обучается исключительно на train; synthetic augmentation применяется
   только к train.
4. При сильном дисбалансе главная метрика — PR-AUC и recall@k, а не accuracy.
