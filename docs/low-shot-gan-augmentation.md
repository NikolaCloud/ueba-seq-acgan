# GAN-дополнение при дефиците аномальных данных

## Цель

Проверить основной тезис работы: помогают ли синтетические MITRE-сценарии,
когда для каждого типа поведения доступно только несколько реальных примеров.

## Протокол

- Используется только train-часть CERT r5.2 для обучения и генерации.
- Из каждого из четырёх CERT-сценариев выбирается 1, 3, 5 или 10 реальных окон.
- В negative class входят 50 000 нормальных train-окон.
- Role-aware conditional GAN прогнозирует нормальный целевой день.
- Профили MITRE калибруются выбранными few-shot примерами и создают по 1 000
  различных окон каждого сценария.
- Вес всей синтетики ограничен 25% positive-class mass, чтобы она дополняла, а
  не вытесняла реальные примеры.
- Результат оценивается на неизменной validation-части из 113 914 окон.
- Проведено шесть запусков с seed 40–45 (включая 42).

## Усреднённый результат

| Реальных примеров на сценарий | PR-AUC без GAN | PR-AUC с GAN | Прирост | Успешных запусков |
| ---: | ---: | ---: | ---: | ---: |
| 1 | 0.0370 | 0.0456 | +23.4% | 5/6 |
| 3 | 0.0368 | 0.0680 | **+84.5%** | 6/6 |
| 5 | 0.0433 | 0.0667 | **+54.0%** | 5/6 |
| 10 | 0.0485 | 0.0994 | **+104.8%** | 6/6 |

При 10 примерах средний Recall@500 вырос с 12.6% до 31.1%.

Каждая группа из 1 000 синтетических окон содержала 1 000 различных финальных
векторов. Средняя вероятность MITRE-дискриминатора для четырёх профилей в
10-shot запуске составила 0.795–0.824.

Полные результаты: `artifacts/r5.2_low_shot_gan/aggregate.json` и шесть
каталогов `artifacts/r5.2_low_shot_gan_seed*`.
