# Презентационные материалы и стенд программы UEBA

В данной директории подготовлены материалы для широкоформатной печати презентационного стенда, архитектурных схем и сравнительных таблиц высокого разрешения.

---

## 📁 Доступные файлы и схемы

```
stand/
├── index.html                 # Главный печатный макет вертикального ролл-апа (60 × 200 см)
├── architecture_73x40.html    # Отдельная страница для печати архитектуры (73 × 40 см)
├── benchmark_table.html       # Отдельная страница для печати таблицы метрик и сравнительного анализа
├── README.md                  # Данная инструкция
└── assets/                    # Векторные схемы (SVG на прозрачном фоне)
    ├── benchmark_table.svg    # Таблица сравнительного анализа и метрик качества (без заголовков)
    ├── architecture_73x40.svg # Крупномасштабная схема архитектуры (73 × 40 см)
    ├── arch_pipeline.svg      # Тракт обработки данных (5 этапов)
    ├── gan_scheme.svg         # Архитектура генератора Seq-ACGAN и слоя инъекции угроз
    ├── augmentation_chart.svg # График прироста качества детекции при дефиците данных
    ├── mitre_matrix.svg       # Матрица эффективности выявления сценариев MITRE ATT&CK
    ├── feature_importance.svg # Диаграмма вклада поведенческих каналов в оценку риска
    ├── xai_deviation.svg      # Схема интерпретируемости решений (Explainable AI, σ-девиации)
    └── logo.svg               # Векторный логотип программы
```

---

## 🎨 Стилистика и оформление
- **Фон:** абсолютно прозрачный (`transparent`), элементы имеют собственные матовые подложки.
- **Шрифты:** **чистый белый цвет** основного текста (`#ffffff`) с контрастными технологичными акцентами (бирюзовый `#38bdf8`, мятный `#2dd4bf`, зелёный `#22c55e`, синий `#60a5fa`).
- **Терминология:** термин «Инференс» заменён на понятные **«Скорость обработки»** и **«Время анализа»**.
